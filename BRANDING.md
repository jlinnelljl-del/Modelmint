# ModelMint3D Branding

This is the current brand direction for the customer-facing ModelMint3D storefront.

## Tone

Light, fun, creative fabrication studio. Slightly purple, a little tabletop/fantasy, polished enough for custom work, but not overly corporate.

Avoid making the site too dark, too cyberpunk, or visually busy.

## Colors

Primary color:

- Plum: `#4B256D`

Accent colors:

- Violet: `#7C4DFF`
- Mint: `#7EE7C1`

Background colors:

- Soft lavender: `#F3F0FF`
- White: `#FFFFFF`
- Light page background: `#FBF9FF`

Text colors:

- Charcoal: `#1E1E24`
- Main text: `#252235`
- Muted text: `#625B73`

## Buttons

Primary buttons:

- Violet/plum gradient background.
- White text.
- Mint border/glow on hover.
- Rounded pill shape.

Secondary buttons:

- White or translucent light background.
- Mint border.
- Charcoal text.
- Mint background on hover.

## Logo

The current SVG mark is a placeholder based on the brand board's angular MM concept. It should be replaced with final designer-exported assets when available.

The final logo should work as:

- horizontal header mark
- square icon
- footer mark
- dark-background mark
- light-background mark

Important: the first letter should clearly read as an `M`, not an `N`.

## Theme File

Storefront brand tokens live in:

```text
modelmint/storefront_static/theme.css
```

Keep new storefront colors in that file first, then reference the variables from page/component styles.
